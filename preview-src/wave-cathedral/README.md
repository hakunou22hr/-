# 波の大聖堂：90秒版

ユーザーが求めた「映画的な背景と動的な部分」を確認するための独立した短いプレビュー。現行版は建築導入12秒＋数学78秒の計90秒。24秒版の演出試作も保存している。教材ライブラリへの完成教材登録は行わない。以下の初版12秒の説明と、末尾の建築導入の説明を参照。

- 大聖堂の背景は、この試作のために画像生成。公開用JPEGは元画像から作成。
- 建築背景の接近は画像の拡大・移動。数式の座標平面、二曲線、金色の領域、反射、塵の位置はThree.jsの透視カメラで投影。
- 正弦曲線、余弦曲線を順に描画。交点π/4と5π/4が発光し、その間の領域のみを金色に満たす。
- 主式はKaTeXで描画。S=∫[π/4,5π/4](sin x−cos x)dx=2√2。
- 12秒、1920×1080、60fps、H.264・yuv420p、音声なし。各フレームを個別生成。
- 本番90秒の完成映像ではなく、背景・発色・動きの方向を示すもの。

再生成はリポジトリルートでローカルHTTPサーバーを4194に起動後、`node preview-src/wave-cathedral/math.cjs`、`node preview-src/wave-cathedral/render.mjs`。数式生成はChromium、動画出力はffmpegが必要。

検証：1920×1080、60fps、720フレーム、12.000秒、H.264を確認し、全フレームを正常デコード。製品ビルドの通常速度完走、停止、シーク、実MP4保存のバイト一致、390px表示を確認。数値積分でも2√2と一致。公開後は専用GitHub Actionsで同じ再生・保存を検査する。

## 建築を主役にした導入 cathedral-v2

大聖堂そのものの演出を求める依頼に合わせ、12秒の建築導入を追加した。正面の身廊、天井を仰ぐ視点、手前の列柱越しの身廊という3つの構図を、画角移動・短いディゾルブ・ゆるやかな光量変化・奥行きの異なる塵でつなぐ。新しい2視点は元の背景を参照して画像生成した。

建築カットは生成画像の拡大・移動・回転による演出試作。建築全体を自由に歩ける3Dモデルではない。前回の数学映像12秒を後半へつなぎ、24秒のMP4にした。元の12秒版も保持する。

`node preview-src/wave-cathedral/render-intro.mjs` で導入と24秒版を再生成する。公開ページには大聖堂だけの12秒版と、3つの背景画像も用意した。

現行24秒版と導入12秒版は、1920×1080・60fps・1440／720フレーム、指定尺と全フレームの正常デコードを確認。24秒版の通常速度完走、停止、シーク、実MP4保存のバイト一致、390px表示、数値積分の一致が通過。

## 90秒版 cathedral-v3

「90秒版は？」という依頼に合わせ、大聖堂の導入12秒と、新しく構成した数学の78秒で90秒版を作成。24秒版の反復や単純なスロー再生ではない。

- 0–12秒：大聖堂の身廊・天井・列柱の導入。
- 12–28秒：正弦曲線と余弦曲線を順に描く。
- 28–42秒：sin x = cos x を解き、区間内の二交点を求める。
- 42–56秒：sin x ≥ cos x の区間を金色に満たし、カメラが領域へ接近。
- 56–62秒：細い帯の高さ sin x − cos x、幅 dx を示す。
- 62–76秒：定積分の立式と原始関数の表示。
- 76–86秒：端点を代入し、√2 − (−√2) = 2√2 を計算。
- 86–90秒：グラフと S = 2√2 を保持する。

新しい式は `math-90.cjs`（ローカルサーバー4198）、数学部分の出力と導入への連結は `render-90.mjs`。出力は `lesson-90s.mp4`。1920×1080・60fps・5400フレーム・音声なしを対象とする。建築背景の方式は前節の画像を用いた演出を継続し、数学の座標と塵は透視カメラで投影する。

90秒版の検証：90.000秒・1920×1080・60fps・5400フレームを確認し、全フレームを正常デコード。各場面の画像変化と数式の表示、通常速度90秒完走、停止、交点・領域内部・計算・最終結果へのシーク、実MP4保存のバイト一致、390px表示が通過。公開後も同じ検査を専用GitHub Actionsで行う。
