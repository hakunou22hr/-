# 数学Ⅲ｜定積分と極限

曲線 y=x²、x軸、x=1 に囲まれる面積を、右端和から求める教材です。同名の外部転送項目を、ライブラリ内で直接利用できる実体に更新しています。他の教材は変更しません。

## 起動

教材一覧の「数学Ⅲ｜定積分と極限」を開くか、`materials/calculus-limit/` を開きます。`?view=video` で動画タブを直接開けます。React / Canvas / KaTeXをローカルにバンドルし、APIキーや追加課金、外部ページへのサインインは不要です。

## 操作

- n=1〜200 のスライダーと 2,4,8,16,32,64,128,200 のボタン
- 2Dと奥行きを持つ3D風の投影表示
- 曲線のみ／長方形のみ／両方
- 数式・近似値・真の面積・誤差の個別表示
- 自動分割再生と停止、手動操作時は自動再生停止
- シアンの曲線、金色の面積・長方形、オレンジのはみ出し
- 右端和の六段階の式変形、左端和による挟み撃ちの説明

## 数学

右端和 `S_n=(1+1/n)(2+1/n)/6`。誤差は `1/(2n)+1/(6n²)>0`、上から1/3に収束します。増加関数なので左端和 L_n と右端和が面積を挟み、`S_n-L_n=1/n→0`。表示値は公式の値を使用し、グラフでは同じ n の長方形を描きます。

参考画像の √x・2/3 は演出の参考として扱い、本教材の対象は x²・1/3 に統一しています。

## 動画

- `public/media/calculus-limit/calculus-limit-90s-pc.mp4` — 1920×1080、30fps、90秒
- `public/media/calculus-limit/calculus-limit-30s-instagram.mp4` — 1080×1920、30fps、30秒
- H.264 / yuv420p / faststart。ナレーション・音声なし。
- 各動画に再生プレイヤーとMP4ダウンロードを用意。

90秒版は0–10秒導入、10–24秒右端和、24–40秒分割加速、40–56秒数式化、56–70秒平方和、70–82秒極限の回廊、82–90秒結論。
30秒版は0–4秒導入、4–10秒分割、10–18秒極限への回廊、18–24秒和・平方和・極限、24–30秒結論。縦型専用に配置しています。

動画では教育用の図の奥行き投影と、背景の矩形ポータル・粒子・浮遊数式が独立して動きます。数式はMathJaxのSVGから鮮明に描画し、字幕は固定した安全領域に置きます。有限のnの近似値を極限値と混同しないよう併記します。

## 再生成

`render/` で `npm install`（@napi-rs/canvas・mathjax-full）後、プロジェクトルートから以下を実行します。FFmpegと日本語フォント Noto Sans CJK が必要です。

```
node materials/calculus-limit/render/render.mjs wide
node materials/calculus-limit/render/render.mjs short
```

`model.js` の数式・タイムラインと `visual.js` の作図を操作教材・映像間で共有します。

## 検証

`node materials/calculus-limit/tests/mathematics.check.mjs` で、長方形を直接足した値との一致、誤差、上下からの挟み撃ち、単調収束、両動画の全フレームの分割数と場面を検証できます。
