# 数学Ⅰ｜三角比で電柱の高さを求める

空間図形を `△ACD`、`△BCD`、`△ABC` の3つの平面に切り分け、三角比と余弦定理を順に使って電柱の高さを求めるインタラクティブ教材です。

## 開き方

- リポジトリ直下で `npm run dev` を実行し、表示されたトップページから教材を選びます。
- 教材を直接開く場合は `/materials/pole-height-trigonometry/` にアクセスします。

## 学習の流れ

1. `△ACD` で `AC = h/√3` を導く。
2. `△BCD` で `BC = h` を導く。
3. `△ABC` に余弦定理を用いて `h = 6√3 m` を得る。

公式ボタンでは sin、cos、tan、正弦定理、余弦定理の意味と、この問題での使いどころを確認できます。
