# 触れる、単位円。
数学Ⅰの三角比から単位円、三角方程式へつなぐ導入教材。既存の trig-cos-equation-3 の前に位置付け、既存教材は変更しません。

## 実行
ライブラリのViteビルド、または静的HTTPサーバーで index.html を開きます。外部ライブラリ・API・フォントの通信は不要です。

## 共通モデルと映画
model.mjs: 範囲、交点、厳密値、180秒の時間軸と字幕。
renderer.mjs: 座標図形、分割格子の頂点変位、3D投影リング、粒子、波紋、動画の描画。
lesson.js: 直接操作、解答表示、自動解説、一時停止と再開。

`node tests/check.mjs` で数値検証。`APP_URL=... PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node tests/check.mjs` で操作と画面幅の検証。

`PLAYWRIGHT_MODULE=... node render/movie.mjs` は共通描画の1920×1080フレームを24fpsのH.264にエンコードします。既定の出力先は public/media/touch-unit-circle-180s-v7.mp4。書き出しはffmpeg、ブラウザ検証はChromiumを使用。

GitHub Actions touch-unit-circle.yml が動画を生成・全編デコードし、新規Release touch-unit-circle-v2 に登録します。既存のPages公開ワークフローは、この動画の生成を待って配信します。Pagesでは同一オリジンのmedia/touch-unit-circle-180s-v2.mp4から配信します。

解答は初期非表示。円全体の交点数と有効範囲内の解の数は別々に表示。角度360°の点は0°と同じですが、解集合では重複せず、全周の範囲は360°を含みません。

実機テストとは別に、1440×1100、1024×768、390×844、844×390のブラウザ表示サイズを検証します。

## 第2版
斜辺2・高さ1・底辺√3の30°の三角形から始め、拡大縮小でsin θ = 高さ/斜辺 = 1/2が一定であることを示します。斜辺を1にすると高さ1/2・底辺√3/2となり、それを半径として単位円を描きます。45°の場合の1/√2とは区別します。図中ラベル・字幕・弧度・解答も縦型分数で統一します。第1版ReleaseとMP4は保持します。

## 第3版：空間と交点の光
背景は頂点ごとに変位する格子、5本の3D投影リングと光の軌跡、78個の流動粒子、交点の床面への光柱と波紋で描画します。交点は白い中心、金／青の発色、拡がる同心円、収束する粒子を重ねます。数学的な円・座標は正面のまま、説明前半は背景を抑え、範囲外の点は薄く残します。動きを抑える設定では演出を静止します。第1・2版の動画と配信URLは保持します。新版はtouch-unit-circle-v3、動画名はtouch-unit-circle-180s-v3.mp4です。

## 第4版：参考画像の構図に合わせた空間
画面の下半分を占める青い遠近格子、画面幅を横切る粒子の帯を伴う立体リング、交点の真下へ降りる垂直光柱、金／青の光だまりと床面の波紋を再構成しました。格子は見えている範囲を細分化して波を描きます。数式は暗いプレートで保護し、単位円に多層の光を重ねます。`?view=equation` は参考画像と同じsin θ=−1/2・θ=330°の実験場面を直接開きます。通常の教材は引き続き斜辺2の導入から始まり、解答は初期非表示です。第1〜3版の動画も保持します。

## 第5版：5種類の映画的背景
粒子の渦、青と金の曲がる時空格子、赤い光の地平線、金色の赤道光を持つ天球、多重アーチの5場面を動的に描画します。動画は学習段階に連動し、場面の冒頭2.8秒でスムーズステップによるディゾルブを行います。操作画面では「背景演出」から選択できます。解説の再生・再開では自動演出に戻り、MP4と時間軸を一致させます。数学の色対応（sinは金、cosは青）、正面の単位円、分数表示、初期非表示の解答は維持します。

`?view=equation&background=vortex#experiment` は粒子の渦を選んだ方程式場面を直接開きます。スマートフォンでは背景メニューをキャンバスの上に分け、数式と重ならないようにします。

## 第6版：散らばる流星の海
参照動画の星空の密度・奥行き・短い光跡をもとに、広い星の天蓋と透視投影された流星群を描画します。約1700個の遠景星、2300個の奥行きのある粒子、24本の長い流星を決定的な時刻モデルで動かします。近い粒ほど大きく速くなり、尾が伸びて画面外へ流れます。自動解説・MP4は連続する流星背景を使い、学習段階ごとの露出を2.8秒で滑らかに調整します。従来5種類はメニューに残します。
`?view=equation&background=meteors#experiment` で流星の海を直接開けます。
