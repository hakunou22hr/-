数学を確かめる — なぜ最大は 5？

条件は x ≥ 0、y ≥ 0、2x + 3y ≤ 12、2x + y ≤ 8。共通部分は、(0, 0)、(4, 0)、(3, 2)、(0, 4) を頂点とする四角形の周と内部です。

x + y = k と置くと y = −x + k。傾きが −1 の直線と領域が共有点をもつのは、0 ≤ k ≤ 5 のときです。

最大値は (3, 2) で 5。このとき y 軸との交点は (0, 5) です。最小値は (0, 0) で 0。接点と切片を区別して見てください。

不等式でも確認できます。二つの条件を足すと、4x + 4y ≤ 20、よって x + y ≤ 5。(3, 2) はすべての条件を満たし、和が 5 になるので最大です。また x ≥ 0、y ≥ 0 から x + y ≥ 0。原点で等号が成立します。

条件が表す領域と、目的の一次式 ax + by を一定にした直線。その共有点がある範囲を調べる考え方が、線形計画法につながります。最大・最小が有限に存在するかは、条件と目的の式によって変わります。
