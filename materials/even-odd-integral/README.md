# 偶関数・奇関数の定積分

教材ライブラリの「数学Ⅲ」から起動。React / Canvas 2D / KaTeX。追加API、ログイン、課金、CDNは不要。既存教材のファイルは変更していません。

## 機能

- 偶関数（x²、cos x、x⁴−x²）、奇関数（x³、sin x、x³−x）の選択
- a = 0.10〜2.50、左右対称区間 [−a,a]、ラジアン
- 偶関数・奇関数・同じaでの比較モード
- 正負で色分けした面積、左・右・合計の解析的積分値
- y軸の鏡面反射、原点中心180°回転、符号付き面積の合体・相殺の模式アニメーション
- アニメーションOFFと動きを抑える端末設定に対応
- 例題の自動再生、一時停止、前後の手順への移動
- 例題1の答え8/3、例題2の答え√2、置換積分による公式の説明
- MP4の再生・シーク・全画面・ダウンロード

面積の数値は原始関数から算出。塗りは符号に応じた細分長方形。グラフは毎回表示範囲内で自動スケールされるため、異なる関数間で縦軸の単位スケールは同じではありません。下部の合体・相殺は符号付き面積の模式図です。0は幾何学的面積の和を意味しません。

## 動画

`public/media/even-odd/` にH.264 / yuv420p / 30fps / faststartのMP4を保存。

- `even-odd-integral-90s-pc.mp4`：1920×1080、90秒、指定の7場面
- `even-odd-integral-30s-instagram.mp4`：1080×1920、30秒、縦型専用の5場面

いずれも字幕で完結する無音動画。生成時のみNode.jsとFFmpegを使用し、再生時の外部API呼出しはありません。数式はMathJaxのSVG、本文はNoto Sans CJKを描画。ブラウザ教材と動画は同じ関数定義を共有します。動画専用の `render/cinematic.js` で、透視投影・カメラ旋回・立体ワイヤー波・光の粒子・残像・面積プレートの合体／相殺を描画します。教材の自由操作用グラフは変更していません。

## ローカル起動・確認

リポジトリルートで `npm install`、`npm run dev`。`/materials/even-odd-integral/` を開く。ビルドは `npm run build`。

数学検証：`node materials/even-odd-integral/tests/mathematics.check.mjs`。数値積分を独立に実行して全関数の左右・全区間の積分と符号反転、例題の答えを確認します。

動画再生成：`npm install --prefix materials/even-odd-integral/render` の後、リポジトリルートで `node materials/even-odd-integral/render/render.mjs short` および `node materials/even-odd-integral/render/render.mjs wide`。FFmpeg、Linuxの `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc` が必要です。別環境ではフォントパスを変更してください。

## 動的演出への改訂（v2）

背景を立体的な数式空間へ変更。青・金の波が奥行き方向にうねり、カメラが旋回・接近します。偶関数は鏡面状のy軸でグラフが反転し、奇関数は原点で180°回転します。面積は発光する板として中央へ集まり、光の輪・粒子の飛散とともに2Sまたは0へまとまります。主数式は読みやすさのため画面に固定。縦型は対称性→面積移動→合体・相殺を専用タイミングで再構成しました。動画URLに版番号を付け、古いキャッシュを避けています。

## 30秒版の背景強化（v3）

縦型だけ背景の明度を上げ、画面上下を走る青・金のオーロラ状ワイヤー波、両端の光柱、螺旋状粒子、奥から手前へ伸びるコメット軌跡、衝突時の多重リングを追加。主数式には局所的な暗い半透明パネルを配置してコントラストを確保しています。90秒版のMP4と教材の操作部分は変更していません。

## 30秒版の奥行き演出（v4）

左右の波状の粒子列と横切るオーロラ状の波線、背景の波状ワイヤーと螺旋リボンを縦型から削除。直線で構成した八角形の光トンネル、長い斜めのコメット、前方へ加速する粒子、回転する三角形の光面に置換しました。数学のグラフと導入の中央波形は保持しています。

## 参考画像に合わせた星雲・粒子波（v5）

縦型の背景を、青い星雲と金・シアンの立体粒子波へ変更。星雲テクスチャは自作の多重スケールノイズから生成した `render/assets/nebula.webp`。星雲の移動・拡大、星の視差と瞬き、波の位相進行、奥行き方向の揺れ、波面を流れる発光粒子をフレームごとに描画します。主数式と面積の説明は画面に固定して可読性を確保しています。

## 30秒版の二部構成（v6）

解説場面の上部にある装飾的な粒子波形を削除。0〜15秒は従来の星雲・星の演出を保持し、15〜30秒は星雲の大きな拡大・回転・移動、逆方向に動く雲の視差、回転・拡大する三本腕の粒子渦、前方へ流れる長い星の軌跡、ゆっくり広がる光輪へ切り替えます。タイトル場面の中央波形は保持し、数式と数学グラフは背景カメラと独立して表示しています。
