# 高校数学の系譜 — Mathematics Genealogy

73概念・124接続・14章からなる静的Web教材。Three.jsの3Dマップ、KaTeXの数式、SVGの動的数学モデルを使用します。バックエンドや課金APIは不要です。

## 既存リポジトリで開く

リポジトリ直下で `npm run dev` を実行し、`/materials/math-genealogy/` を開きます。教材一覧にも material.json から自動追加されます。`npm run build` は既存教材と一緒に dist/ へ出力します。既存のGitHub Pagesワークフローを利用できます。

## 今回の画面・可視化の改善

グラフを上部のメインラボへ移動し、系譜MAPは下部の220〜260pxのコンパクト表示へ縮小しました。MAPは必要なときだけ拡大できます。単位円の点・二次関数の頂点・微分のP/Q・積分の境界点・ベクトルの先端を直接ドラッグでき、対応する部分を発光で強調します。点の鼓動、グラフの光彩、操作時の数値の強調、面積のゆっくりした発光を追加。「発光・鼓動」で切り替えられ、動きを減らす設定では初期OFFです。

## 操作

- ノード：クリック／タップで概念へ移動。検索も可能。
- 3Dマップ：ドラッグで回転、スクロール／ピンチで拡大。2Dへの切替、科目フィルター、自動回転、全体へ戻る。
- 関連：前提・発展先または接続線を選ぶと光が移動し、関係の種類・説明・二つの式を表示。
- モデル：スライダー、選択メニュー、点のドラッグで変更。「動きを止める」で固定。「⛶」で拡大。
- 自動再生：14章を順に再生。一時停止・再開、場面の前後移動、章ジャンプ、再生位置変更。Spaceでも再生・停止。
- 授業用設定：式、解説、関連線、自動的な動きを切替。
- 探究：概念の関連を予想して選び、正解の接続と理由を確認。

## データと数式

- src/data.js：concepts / connections / chapters / subjects / relation type
- src/math.js：解・導関数・面積・二項分布・相関・方べきの数値計算
- src/models.js：SVGモデル、パラメーター、標本抽出・コイン実験
- src/universe.js：WebGLマップ・立体モデル・Canvasフォールバック
- src/main.js：画面、授業用操作、再生、探究
- src/style.css：レスポンシブ表示・発光・動きの低減設定

概念はID、科目、式、説明、モデル、3D位置を持ちます。接続はID、起点、発展先、関係の種類、理由を持ちます。必須の主要単元には入る関連と出る関連を用意しています。全体図は発見の歴史順や必修の履修順を示すものではありません。

## 数学上の留意点

- 二項定理は数学Ⅱ、データの分析は数学Ⅰ、方べきは数学Aとして分類。
- 三角関数の微分はラジアン。角度操作の入力は度から変換。
- 積分モデルは f(x)=1+x²/4 の [0,4]、中点による区分求積。正確な値は28/3。
- 回転体は別モデル y=√x、[0,4]、x軸周り。体積は8π。
- 円錐の断面は、半径(2−y)/2の円錐と平面 y=−0.5−0.4z の実際の交線。媒介変数モデルの楕円とは別のモデルと明示。
- コイン投数nと実験の反復回数を区別。正規曲線は二項分布の近似で、nが小さいと不正確。実験の反復だけで正規分布に変わるわけではありません。
- 3Dコインは投げ上げのイメージ。確率の結果は乱数による独立試行で計算します。
- 相関係数は分散が0のとき定義できません。相関は因果関係を意味しません。
- 信頼区間の概念式は母標準偏差が既知で正規近似が適切な場合。標本抽出モデルでは標本平均の変動を示します。

## 追加した関連と操作

自然対数・eと正規分布、無限級数・区分求積と回転体、二次曲線と媒介変数、二次方程式・相似と方べき、整数とユークリッドの互除法を接続しました。正規分布はμ・σ・区間、等比級数は公比と項数、互除法は二つの整数、eは近似の項数を操作できます。無限級数と区分求積の違い、発展内容も関連の説明に記載しています。
