# 数学Ⅰの三角方程式、円利用

一般の円と直線の交点を使い、三角方程式を視覚的に探る高校数学Ⅰの教材です。教材ライブラリのカードから起動できます。

## 使い方

リポジトリのルートで `npm install` → `npm run dev`。`/materials/trig-equations-circle/` を開きます。`npm run build` で既存のライブラリと一緒に dist に出力され、既存の GitHub Pages ワークフローで配置できます。外部 CDN やサーバー API は使いません。

1. 問題を切り替え、式変形でどの座標を見るか予想します。
2. 「角度ラベルを隠して探る」で答えを伏せ、スライダーを動かします。交点の位置は残るので、図から角度を探せます。
3. θ自動再生は1秒に12°進み、次の解で一時停止します。再度再生すると次へ進みます。「次の解へ」は解の角度へ滑らかに移動します。
4. 半径を1・√2・2・3に変え、円と条件の線の変化、角度の不変性を比較します。
5. 解説・発問の切替、半径の説明、3D表示のドラッグ回転・拡大を授業に合わせて使います。

初期画面は特に重要な問題(2)、θ=20°です。初期化は現在の問題の半径、角度、視点、発見記録を戻します。記述欄はその問題を考える一時的なメモで、問題切替・ページ再読込で消えます。保存や個人情報の送信はありません。

## 数学的背景と解答

P=(r cosθ,r sinθ)、r>0。上半円が0°≤θ≤180°に対応します。OP=rは直角三角形の斜辺、横の辺の長さは|x|、縦はy。第2象限でxが負であることと、辺の長さが負でないことを区別します。軸上では三角形は退化します。

|問題|標準半径|条件の線|解 θ|
|---|---|---|---|
|cosθ=0|2|x=0|90°|
|√2 sinθ=1|√2|y=1|45°,135°|
|tanθ+1=0|√2|y=−x の左上の半直線|135°|
|2 sin(180°−θ)=1|2|y=1|30°,150°|

(2)は交点(1,1),(−1,1)。r=√2にするとy=r/√2=1であり、左右の交点が同じsinを持ちます。2点を常時鼓動させて強調します。

(3)はy/x=−1、x≠0。0°〜180°で負の傾きを持つ方向は第2象限です。90°でtanは「定義されない」と表示します。

(4)はφ=180°−θと置くとφも0°〜180°。φ=30°,150°に対しθ=150°,30°。Pと補角の点Q=(−x,y)はy軸対称で、sinφ=sinθ。最終解はθ=30°,150°です。

半径変更時はsinθ=aに対してy=ra、cosθ=aに対してx=raを連動させます。座標目盛の尺度を固定しているので、円の大きさの変化を直接比較できます。値は小数第3位までの近似、解判定は角度差0.051°未満です。3D表示はThree.jsの平面をOrbitControlsで回転・拡大・移動します。数学的な角度・座標は元の平面上で計算します。WebGL非対応では2Dを使えます。

## 授業のねらい

式変形 → 比の意味 → 座標の条件 → 円との交点 → 範囲内の全解、という流れを経験します。「半径を変えると何が変わるか」「第2象限にも解がある理由」「補角の高さが等しい理由」を、生徒の記述と対話で確かめてください。

## 構成と検証

`math.js` が問題データと数学計算、`main.js` がSVG描画と操作、`style.css` が応答的レイアウトとアニメーションです。教師が変更しやすいよう、半径・解・解説を問題データにまとめています。動きを減らすOS設定に対応し、スライダー・ボタンはキーボード操作できます。

ルートで `npm test -- materials/trig-equations-circle/math.test.js`、`npm run build`。図の解答と元の方程式、補角、半径変更、tanの未定義を検証します。

## 3D表示の描画方式

円・弧・半径・補助線はThree.jsの線と管、点は球、角度の領域は面として直接描画します。SVG画像のテクスチャ貼付けは使いません。ラベルはCanvasの文字スプライトで、視点に向かって表示します。xy平面に対する視点回転を分かりやすくするため、視点用のz軸を薄く表示します。数学上の点のz座標は0です。

図中の横の辺にxの実際の値、縦の辺にyの実際の値を小数第3位まで表示します。スライダー・自動再生・半径変更と連動し、3Dでも同じ値を表示します。xは第2象限で負になります。
