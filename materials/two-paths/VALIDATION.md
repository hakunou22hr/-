# 検証記録

## 数学・描画

`render/check.mjs`：216場面を検証。90秒横型、30秒横型、30秒縦型設計の3構図について全6章の12位置で主役数式と字幕の画面内配置・重なりを確認。各章で背景が動き、同じ時刻へ戻ると同じ画面を再現することを確認。

区間 [-7,7] の正負のxで独立した数値積分を実施。被積分関数の積分、分解した二つの積分、端点評価1−cos x、導関数sin xの一致を検証。上端と下端の順序、+x cos x と −x cos x の符号を確認。

既存教材 `npm run test:trig-cinema` 通過。新作は独立したmaterials/two-pathsとpublic/media/two-pathsの追加のみ。既存3教材197ファイルのハッシュを比較して保持を確認する。

## 出力仕様

フルHD 1920×1080、30fps、H.264 yuv420p、BT.709、AACステレオ。90秒2700フレーム／30秒900フレームをffprobeで確認し、FFmpegで全編デコードする。
視聴用は1280×720 Baseline H.264、最大2.1Mbpsとし、原版を別にダウンロードできる。
音声は独自合成。90秒PCMのピークは−7.4dBFSでクリッピングなし。

## 制限

配布MP4は90秒・30秒とも横型。9:16は描画実装と配置検証を備えた設計であり、縦型MP4は今回の配布に含めない。
プログラム描画の滑らかさは端末性能に依存する。通常の視聴では軽量MP4を使用。

## ブラウザ確認

30秒版：Chromiumの実時間再生、3Mbps・100ms遅延、開始後の再バッファリングなしで終了まで到達。一時停止、シーク、リセット、音量、ミュート、全画面、プログラム描画への切替を確認。ライブラリ検索から作品へ遷移し、実ダウンロードの全バイトが原版と一致。390px幅のモバイル表示で横はみ出しなし。実機iPhone等は未検証。

公開後は `.github/workflows/two-paths-review.yml` で実際のGitHub Pages URLに対して同じ全編再生とダウンロードの検査を行う。

90秒原版：1920×1080、2700フレーム、映像・音声とも90.000秒、72,628,878バイト。30秒原版：1920×1080、900フレーム、映像・音声とも30.000秒、24,725,851バイト。両原版はFFmpeg全編デコード通過。

本番ビルド：ライブラリ検索・作品への遷移、90秒／30秒それぞれのネイティブ再生・シーク・3層プログラム描画の読み込みを確認。ページのJavaScriptエラーなし。

最終検証：横型90秒・30秒の両版について3Mbps・100ms遅延のChromiumで全編再生、再バッファリングなし。両版の一時停止、シーク、リセット、音量・ミュート、全画面、Canvas切替を確認。両MP4の実ダウンロードが原版と全バイト一致。390px表示の横はみ出しなし。結果はverification.jsonに保存。
