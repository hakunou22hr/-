THE MATHEMATICS

直線を動かすと、和の限界が見える。

領域：x² + y² ≦ 10、y ≧ −2x + 5。円と境界線の交点は (1, 3) と (3, −1)。

x + y = K は傾き −1 の直線。小さい K から近づけると (3, −1) に最初に触れ、K = 2。大きい側では円との接点 (√5, √5) に最後に触れ、K = 2√5。

最大値のとき、黄金の直線の y 切片は (0, 2√5)。円との接点 (√5, √5) とともに画面内で確認できます。

MINIMUM 2(3, −1)

MAXIMUM 2√5(√5, √5)

最小点は円と境界線の交点であり、黄金の直線が円に接する点ではありません。奥行き・回廊・反射は映像演出です。図形は同一の x-y 座標平面上にあります。

AFTER THE FILM · 判別式で確かめる

最大値の K は、どう見つける？

動画では、直線が円に最後に触れる瞬間を見ました。そのときの K を、円と直線の共有点の個数から求めます。以下では動画の k と同じ定数を K と書きます。

  1. 直線の式を円の式に代入する

    境界の円 x² + y² = 10 と、黄金の直線 x + y = K を連立します。y = K − x を代入すると、

    x² + (K − x)² = 10
    2x² − 2Kx + K² − 10 = 0

    この二次方程式の実数解が、円と直線の共有点の x 座標です。

  2. 判別式 D で、共有点の個数を調べる

    D = (−2K)² − 4·2·(K² − 10)
    = 80 − 4K² = 4(20 − K²)

    D > 0共有点は 2 個（円を横切る）

    D = 0共有点は 1 個（円に接する）

    D < 0共有点はない（円から離れる）

    領域は円の内部にあるので、領域を通る直線は円とも共有点をもちます。したがって D ≧ 0 が必要です。

    D ≧ 0 ⇔ K² ≦ 20
    −2√5 ≦ K ≦ 2√5

  3. 大きい側で円に接する K を選ぶ

    共有点が 2 個から 1 個に変わる限界では、D = 0 です。

    D = 0 ⇔ K = ±2√5

    K を大きくする方向の限界は K = 2√5。この値が実際に今回の領域で取れるか、接点を調べます。

  4. 接点が、指定された領域に入るか確認する

    D = 0 のとき、二次方程式は重解をもちます。

    x = −(−2K) / (2·2) = K / 2
    y = K − x = K / 2

    K = 2√5 を代入すると、接点は (√5, √5) です。

    x² + y² = 5 + 5 = 10
    y + 2x − 5 = 3√5 − 5 > 0

    円周上にあり、y ≧ −2x + 5 も満たします。上限の K = 2√5 が領域内の点で実現するので、

    x + y の最大値は 2√5そのとき (x, y) = (√5, √5)

y 切片と、円との接点を区別しよう

x + y = K に x = 0 を代入すると y = K。最大値の直線の y 切片は 2√5、y 軸との交点は (0, 2√5) です。円との接点 (√5, √5) とは別の点です。

なぜ、最小値を D = 0 で求められない？

判別式だけで分かるのは、円と直線の関係です。K = −2√5 の接点 (−√5, −√5) は y ≧ −2x + 5 を満たさず、今回の領域には入りません。

今回の領域での最小値は、円と境界線の交点 (3, −1) での K = 2。このとき D = 64 > 0 なので、黄金の直線は円の接線ではありません。

確認問題：K = 5 の直線が領域を通らない理由は？

D = 4(20 − 25) = −20 < 0。円との共有点がないため、円の内部にある今回の領域も通りません。
