# 数学A 確率 — 立体の袋から3個の玉を取り出す

白玉3個・赤玉4個・黒玉5個の袋から、同時に3個取り出します。ユーザーの訂正に基づき、問題は次の3条件です。

1. 3個とも玉の色が異なる
2. 3個の玉の色がすべて同じ
3. 3個の玉の色が2種類

## 使い方

教材ライブラリのカードまたは `/materials/probability-metal-balls/` を開きます。リポジトリルートで `npm install` → `npm run dev`。`npm run build` で既存のGitHub Pagesワークフローに含まれます。

「3個を同時に取り出す」で3球が同時に袋から上がり、並びます。金属球はThree.jsの実際の球メッシュと反射材質で描画します。ドラッグ回転、ホイール・ピンチ拡大、袋の透過切替、視点リセットができます。条件に合う抽選では赤い光、不一致では水色の光で選ばれた球を強調します。袋は布のように粗い材質と縫い目を持つ開口メッシュで、見通しを優先して初期状態は透過しています。

1試行では戻さず3個を選びます。次の試行の前に必ず12個に戻します。連続実験と100回高速実験が可能です。100回実験は99回を数値で計算し、最後の1回を立体表示します。「玉を袋に戻す」は記録を消しません。「実験記録をリセット」で統計を消します。

全220通りの一覧では、1マスが番号の異なる3球の組です。条件に合うマスだけ明るくなります。マスを選ぶと、その組を立体表示します。この指定表示は無作為の実験記録に加えません。

分母・分子の予想を入力し、「予想を確かめる」で検証できます。考え方と解答は初期状態で非表示。解答ボタンで表示します。色のパターン一覧と全体のマスは最初から参照できます。記述メモや実験記録はページ内でのみ保持され、再読み込みで消えます。

## 数学的背景

玉を番号で区別し、等確率の組を数えます。分母は12C3=220。色だけの10パターンは等確率ではありません。取り出した順番も区別しません。

|条件|分子の数え方|確率|
|---|---|---|
|すべて異なる|3C1×4C1×5C1=60|60/220=3/11|
|すべて同じ|3C3+4C3+5C3=1+4+10=15|15/220=3/44|
|2種類|12+15+18+30+30+40=145|145/220=29/44|

2種類の直接計算：白2赤1は12、白2黒1は15、赤2白1は18、赤2黒1は30、黒2白1は30、黒2赤1は40。余事象では220−15−60=145。3条件の通り数の合計は220です。

抽選は個体の組全220通りからMath.randomで1組を一様に選ぶモデルです。球の物理衝突から抽選する方式ではなく、数学モデルで決めた3個を同時にアニメーションします。見た目の場所で抽選確率が変わりません。実験の割合は有限試行では理論値と一致しないことがあります。

## 探究の発問

- 分母を「10色パターン」にすると、何が間違うか。
- 同時に取り出すのに、白赤黒と赤白黒を別に数えてよいか。
- 白だけより黒だけが出やすい理由は何か。
- 色が2種類のとき、2個取る色と1個取る色をどう分けるか。
- 1種類・2種類・3種類の合計が全体になるのはなぜか。
- 実験の回数を増やすと、理論値との関係はどう変わるか。

## 実装と検証

`math.js`に220組の列挙と判定、`scene.js`に袋・金属球・同時取り出し、`main.js`に発問・全組の表示・実験統計を分離しました。教師向けのコメントを付けています。Three.jsはリポジトリの既存依存を使い、外部画像やCDNは不要です。

`npm test -- materials/probability-metal-balls/math.test.js`で全体、3条件の分割、10パターンの重み、全220組の抽選可能性を検証します。`npm run build`で公開用ビルド。WebGL非対応では代替の説明と2D結果表示に切り替え、数学の探究は利用可能です。ブラウザでの3D描画の実機検証はこの作成環境では未実施です。

取り出し経路は `motion.js` に分離しています。袋の口を3つの別々の位置で通り、球半径0.29に対して中心距離0.68以上を保ちます。`motion.test.js` は全220組について101時点の球間距離を検証します。抽選確率は変更していません。
