STEP 02

なぜ、できたりできなかったりする？

どの2辺を選んでも、その和が残りの1辺より大きい必要があります。

✦ 考えてみよう

3辺が 3，4，x のとき、成立条件はどんな3本の式になるだろう？

① xを動かす→② 3辺の条件を式にする→③ 同時に満たす範囲を探す

3 と x の和3 + x > 4

x < 7x > 1x > −1

STEP 03

3つの条件を、数直線で重ねる

条件をオン・オフして、重なっている範囲を見よう。

3つの共通部分1 < x < 7

x > −1 も必要ですが、x > 1 を満たせば自動的に満たされます。

STEP 04

鋭角三角形は「最大の角」に注目

最大の角が90°未満なら、ほかの2角も必ず90°未満です。

3つ全部を調べる？最大の角だけ
調べればよい！

一番大きい角は、一番長い辺の向かい側。

いまの x で比べる
4>3.0

最大辺は 4 → 辺4の向かいの角に注目

✦ 考えてみよう

4 と x のどちらが一番長い？ x が4をまたぐと、注目する角が切り替わります。

STEP 05–06

最大辺で場合分けし、余弦定理を使う

カードを開いて、鋭角になる不等式を順番に追おう。

最大辺 4

辺4の向かいの最大角を α とする

余弦定理
cos α = 32 + x2 − 422・3・x
α < 90° ⇔ cos α > 0
32 + x2 − 422・3・x > 0

x > 0 では分母 2・3・x は正。だから分子だけを調べればよい。

x2 − 7 > 0→x > √7 または x < −√7→ x > 0 と x ≦ 4√7 < x ≦ 4
最大辺 x

辺xの向かいの最大角を β とする

余弦定理
cos β = 32 + 42 − x22・3・4
β < 90° ⇔ cos β > 0
32 + 42 − x22・3・4 > 0

分母 2・3・4 は正。分子が正になる範囲を調べよう。

25 − x2 > 0→x2 < 25 → −5 < x < 5→ x ≧ 44 ≦ x < 5
STEP 07

二次不等式を「形」で確かめる

数直線と放物線を切り替えて、正になる場所を確認しよう。

y = x2 − 7

外側が正 → x < −√7，√7 < x

y = 25 − x2

内側が正 → −5 < x < 5

STEP 08

得られた範囲を、最後に合わせる

場合1と場合2は x = 4 でつながり、成立条件の内側にあります。

（1）三角形が成立1 < x < 7
（2）鋭角三角形√7 < x < 5

√7 ≒ 2.65。端では直角三角形になるため、どちらも含みません。
