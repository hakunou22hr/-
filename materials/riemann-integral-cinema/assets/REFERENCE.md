# 参照背景

- 参照サイト： https://integral-universe-preview.hakunou22hr.chatgpt.site/
- サイト名：積分が示す
- 参照した公開版：12
- ソースコミット：261cb21a3cb78e5bb718491f4edfe208ddbb2304

- この教材内のファイル：reference-parts.png

ユーザーが指定した背景素材を、元のPNGのまま複製して使用している。参照サイトは変更していない。

元サイトのScene.tsxを確認し、赤青の点群曲面、軌道リング、星の運動を動画側へ適用した。こちらの動画ではPNGをそのまま拡大・移動するのではなく、推定奥行きを持つ32×18の変形メッシュに貼り、頂点を時刻から更新する。3D点群・曲線・軌道・スキャン面は別に計算して動かす。

背景の曲面は演出用。区分求積の計算には、math.jsの連続関数・右端値を用いる。
