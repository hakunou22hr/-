# e^x > 1+x を、グラフ・導関数・接線から探究する

「予想 → 実験 → 差 → 微分 → 増減 → 基準点 → 証明 → 発展」の8段階で指数不等式を探究する、独立したViteエントリです。

## 起動と一覧への登録

リポジトリルートで `npm run dev` を実行し `/materials/calculus-inequality-proof/` を開きます。`material.json` は既存の `src/materials.ts` によって自動的に一覧カードと検索へ登録されます。Vite の既存の複数ページ設定で Pages 用のビルド対象にも自動追加されます。

公開先（main に反映して既存 Pages ワークフローが成功した後）：
`https://hakunou22hr.github.io/-/materials/calculus-inequality-proof/`

## 操作

- x は −3 から 4、刻み 0.01。比較・差・導関数・接線・3Dは同じ値を共有します。
- 2Dは比較・差を上段の2列、導関数と関係カードを下段に配置。共通スライダーを上部に固定し、同じ x で「差＝Rの高さ」「接線の傾き＝Sの高さ」を確認できます。スマートフォンでは1列でスライダーを維持します。
- 2Dの縦軸は選択した点に応じて自動調整。3Dは全層共通の線形縮尺で、z は数学の変数ではなく証明の階層です。
- 3Dはドラッグで回転、ピンチ／ホイールでズーム。正面表示とリセットが可能です。
- 再生は9段階、速度4種類。一時停止・再開・再実行時にタイマーは重複しません。
- WebGL初期化失敗／コンテキスト喪失時は2Dを維持します。
- 発展では予想を選択して負の x に動かした後に、全実数での結論を表示します。
- 教師用表示、即時解説、知識マップ、接線・凸性・自然対数の練習を備えます。

## 数学

`f(x)=expm1(x)−x` は `exp(x)−(1+x)` と同値で、0付近の桁落ちを抑えます。`f′(x)=expm1(x)`、`f(0)=0`。導関数の正値だけから関数の正値を結論せず、増加と基準点を必ず組み合わせます。負の領域では減少して0へ至るため差は正。自然対数は定義域と単調増加を明記します。

`npm test -- materials/calculus-inequality-proof/src/math.test.ts src/materials.test.ts` で数式・符号・接線・一覧登録を検証します。ブラウザー検証は Chromium のソフトウェア WebGL と390×844／820×1180のビューポートを使用。iOS実機の検証とは区別します。
