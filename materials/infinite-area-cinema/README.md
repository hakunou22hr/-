# 無限が、面積になる瞬間

問題：lim(n→∞) Σ(k=1…n) (2+3k/n)² · 3/n = ∫₂⁵ x² dx = 39。

- 120秒版：授業用。区間、幅・高さ、細分化、積分、計算の7章。
- 30秒版：同じ7章を短編として再編集。横長1280×720 / 24fps。
- 日本語字幕、オリジナル合成BGM・効果音入り。ナレーションなし。
- 計算用の長方形は右端和。有限の和は `39 + 31.5/n + 4.5/n²`。

## 再生成

必要：Node.js、Python 3 + NumPy、FFmpeg、Noto Sans CJK JP。

```sh
npm install --prefix materials/infinite-area-cinema/render
python3 materials/infinite-area-cinema/render/audio.py work/infinite-area-v6
DURATION=120 node materials/infinite-area-cinema/render/render.cjs
DURATION=30 node materials/infinite-area-cinema/render/render.cjs
python3 materials/infinite-area-cinema/render/verify.py work/infinite-area-v6
```

数式はMatplotlibで正確に組版した透過PNGをBase64テキストで保持する。`assets/*.png.b64` をレンダラーが直接読み込む。
各版は章ごとの時間配分を変えて描画し、音はピッチを保って尺へ合わせる。
検証済み30秒MP4は `public/media/infinite-area/` に保持し、通常のPagesデプロイで公開する。120秒MP4はサイト容量を増やさないようarchiveに保管する。

## 映画版 v2

参考イメージに合わせて背景と撮影を再制作。`render/assets/environment.png` は画像生成した濃紺の霧と反射床のプレート。カメラに合わせた移動と拡大、独立して流れる霧、微粒子と光条を重ねる。数式と図形は生成画像に含めず、正しい数式を別途合成する。

図形は透視投影した平面。ショットごとに接近・旋回・後退し、長方形と曲線を床へ反射させる。反射のフェードと水面の揺れは光学演出であり、面積の計算には含めない。計算・積分の場面ではカメラを正面近くへ落ち着かせる。

旧版はGit履歴の `05df268` に保持。現在のMP4、ポスター、教材カードを映画版へ更新。

## 動的な嵐の映画版 v3

`render/storm.cjs` が各フレームの雲の流れ場・密度・色と局所照明を計算する。写真は雲と床の素材としてサンプリングし、空は変形したサンプリング座標で再構成する。青・紫・金の光が移動し、雲はカメラが静止していても変形する。

`render/storm.json` を映像と音声で共用。枝分かれした放電、雲の局所発光、床の反射と広がる波紋を7回のタイミングに同期させる。雷鳴は閃光の0.22秒後に始まり、左右の定位と遅延反射を持つ。計算の章は放電を止め、式を読みやすくする。

音声は30秒・120秒をそれぞれ48kHzステレオで生成し、時間伸縮で同期をずらさない。旧版はGit履歴の `ab066f5`。

## 粒子演出・操作版 v4

空の画像変形を撤去。`effects-core.js` が、煙の発生・風の力・拡散・冷却・消散、火花の放物運動、爆発と衝撃波を描く。写真を使うのは平面の床だけ。動画と操作プレビューは同じ粒子エンジンを使う。

ページの「吹き込み・放電・爆発」は入力位置と時刻から新しい演出を発生させる。分割数スライダーは正しい右端和を再計算して吹き込みを発生させる。リセットで手動イベントを取り除く。MP4は同じ演出を時系列に収録した映像で、操作プレビューと区別して案内する。v3で確認済みのステレオ雷鳴は変更しない。

## 幾何学的な煙の映画版 v5

煙が立ち込める濃紺の空間と反射床に戻し、曲線・点群・薄い網目の立体波面を透視投影する。左右の煙に沿う面がねじれ、等高線上を光が伝わり、細い軌跡が面からほどける。元画像の画素をゆがませる処理、粒子の吹き込み、爆発、火花、衝撃リングは使用しない。

操作は「流れを集める・光の波・渦をつくる」。入力位置と時刻が3D頂点へ作用する。数学の図形を背後の幾何学から区別し、中央は発光を抑える。動画の遠雷と音楽は承認済みの音声を維持。操作時の音は穏やかな共鳴音へ変更する。

## 明瞭なフラクタル模様と轟く雷鳴 v6

大小3段階のうねりを重ね、網目を49×21点へ高密度化。線幅・発光・点群を強め、中央の数式には読みやすさを保つ減光域を残す。

雷鳴は30秒版24回・120秒版84回。`storm.json` の時刻を映像と音声で共有し、従来の主要な合図を保ちながら増やす。低音・中低音・短い雷の立ち上がり・左右の遅延残響を重ね、4.8秒の尾が次の雷鳴とつながる。波形はソフトリミッターで整え、ステレオ音声のピークとRMSを記録する。操作プレビューの「光の波」でも同じ音源を再生できる。

## v7 雷の映像演出

音声の雷イベントと同じ時計で、伸びる放電路、枝分かれする稲妻、主閃光と副閃光、霧・網目の照明、床の反射と残光を描画。雷鳴は閃光から約0.1秒遅れて響く。30秒24回／120秒84回の音声を維持。数式は雷の背景より後に描き、読みやすさを確保。操作プレビューの光波にも放電が連動する。

## v8 空間全体の雷

雷源を左右固定から画面幅全域に再配置。地面へ落ちる雷、上空を横断する雲間放電、雲内で広がる面発光を組み合わせ、距離によって太さと明るさを変える。音声の左右定位も新しい雷源に合わせて再生成。30秒24回／120秒84回。
