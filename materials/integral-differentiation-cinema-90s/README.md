# 定積分と微分法：90秒映画型教材

2026年10月16日、ユーザーの指示で動く背景の確認済み90秒版を教材ライブラリへ保管。

- `index.html`：音声付き再生・MP4ダウンロード。
- `archive.json`：動画のURL、SHA-256、形式、再現元コミットと検証記録。
- `source/`：実際に動画を描画したソースツリーをそのまま固定したスナップショット。元のREVIEW.mdは制作時の記録として保持。
- MP4はGitHub Releasesの既存ファイルを保存先とし、再エンコードせず同じ映像を参照。
- 1920×1080、30fps、90.000秒、2700フレーム、H.264 / AAC。背景音楽あり、ナレーションなし。
- 背景は参照画像をもとに生成した画像に、変形・光の波・流れ・数式レイヤーの動きを合成。学習対象の数式はKaTeXで描画し、背景の装飾的な数式と区別。

再現にはリポジトリルートで依存関係をインストールし、source/ をViteでビルド・配信後、source/render/render.mjsをCINEMA_EDITION=lessonで実行する。使用したワークフローはコミット29b1e390eca7bb86c2c1e8ac41acf1442747bbe2の.github/workflows/integral-cinema-review.ymlを参照。

元の三角関数の不定積分教材、既存の定積分と微分法教材、縦型30秒版は保持。
