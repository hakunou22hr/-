関数 f(x)=x−4√x の最大値・最小値を探る

導関数の符号を 2D・3D で動的に可視化する教材

QUESTION

どこで減って、どこで増える？

f(x) = x − 4√x0 ≤ x ≤ 25

一番小さくなるのはどこだろう？

一番大きくなるのは、途中の点か、それとも端だろうか？

01 / GRAPH

まず、曲線の形を観察しよう

点を動かして、接線の傾きが変わる様子を確かめよう。

● 現在地● 最小候補● 端点
02 / DIFFERENTIATE

1行ずつ微分してみよう

行を選ぶと、その計算の意味が光ります。

💡 補足： (√x)′ = 1/(2√x)。x=0 では分母が0になるため、この導関数の式は使えません。端点は関数値を直接調べます。
03 / SIGN OF DERIVATIVE

どこからマイナス、どこからプラス？

分母はいつも正。光る分子の符号に注目しよう。

f′(x) = √x − 2 / √x
＋ 正

05 / VISUALIZE

06 / CONCLUSION

発見を、解法として整理しよう

  1. f′(x) = 1−2/√x = (√x−2)/√x
  2. f′(x)=0 ⇒ √x=2 ⇒ x=4
  3. 0<x<4 で減少、4<x≤25 で増加
  4. 端点と臨界点を比較：f(0)=0,　f(4)=−4,　f(25)=5
最小値 −4x=4
最大値 5x=25
なぜ端の値も比べるの？導関数が0の点は「途中で増減が変わる候補」です。閉区間での最大・最小は端点で起こることもあるため、臨界点と両端の関数値をすべて比べます。
