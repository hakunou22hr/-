# 数学Ⅱ 弧度法 — 円を動かしてラジアンを発見

円周上の点Pを動かし、伸びる弧と半径の比からラジアンを理解する探究教材です。添付された弧度法・扇形のスキャン資料の内容（1ラジアン、換算、弧長と面積）を参考に、独自の図と発問を作成しました。資料の画像や個人情報は公開ファイルへ収録していません。

## 起動・公開

教材ライブラリのカード、または `/materials/radian-arc-explorer/` を開きます。開発はリポジトリルートで `npm install`、`npm run dev`。`npm run build` で既存のライブラリとともに `dist/` に出力され、既存のGitHub Pagesワークフローで公開できます。外部CDNへの依存はありません。Three.jsは既存の依存を利用します。

## 操作

- スライダーまたは円のドラッグで累積角を0°〜720°の間で変えます。円のドラッグはポインタの角度の変化に合わせて回転します。
- 自動再生は点を滑らかに進め、弧の長さと換算を連動させます。速度は変更でき、720°で停止します。
- 「1 radへ」で弧と半径が等しい位置へ移動します。基準角ボタンや「次の基準角」で換算を比較します。
- 半径1〜3を動かすと、座標目盛を固定したまま円の大きさと弧長が変化します。
- 度、通常のラジアン、π radの係数を入力できます。`7/6`などの分数も入力できます。
- 3D表示はThree.jsの平面をドラッグして視点回転、ホイール・ピンチで拡大、右ドラッグ・2本指で移動します。「視点を初期位置に戻す」も使えます。3Dでは点の移動はスライダーで操作します。数学の計算は元のxy平面で行い、見かけの角度と区別します。WebGL非対応では2Dに戻ります。
- 3つの学習モードで発問と解説を切り替えます。記述欄は一時メモで、再読み込みすると消えます。
- 換算練習は210°・240°・330°、5π/4・3π/2。解答を入力してから円で確認できます。

## 数学的背景

θ（ラジアン）=ℓ/r。半径と等しい弧に対する中心角が1 radで、約57.296°です。1周の弧は2πrなので、1周は2π rad。180°=π radより、度→radはπ/180、rad→度は180/πを掛けます。

点P=(r cosθ,r sinθ)。θは累積角なので、360°と720°で座標は同じでも弧長は異なります。1周目の弧を水色、2周目の弧を紫色で区別しています。紫の弧は重なりを避けるため描画上だけ少し外側にずらし、数値の弧長は半径rで計算します。

下の直線図は弧を「半径r何個分か」で並べる正規化図です。目盛1区間はr、12.566…区間が2周です。半径変更ではこの比が一定であることを比較します。

ℓ=rθ、S=r²θ/2=rℓ/2にはラジアンを使います。1周内の扇形の面積と、周回で同じ領域を重複して数える累積掃過面積は別表示です。360°ちょうどでは1周内の余り角は0°、累積面積はπr²です。

資料の例：r=10、θ=π/6ではℓ=5π/3、S=25π/3。画面ではr=1〜3で比例関係を探究します。

## 授業の発問

1. 半径と同じ長さまで弧を進めると、何度になるか。
2. 半径を大きくしても1radが同じ角度になる理由は何か。
3. 半周がπradになる理由を円周から説明できるか。
4. 1周を超えて点が同じ位置に戻っても、角度や弧長が増えるのはなぜか。
5. 半径を2倍にしたとき、弧長と扇形面積はそれぞれ何倍になるか。

## コードと検証

`math.js`は換算・座標・弧長・面積、`main.js`はSVG図と学習操作、`plane3d.js`はThree.jsの平面とカメラ操作です。数値は小数第3位まで、基準角は約分したπの分数で表示します。

`npm test -- materials/radian-arc-explorer/math.test.js`で換算、周回、半径比較、資料の扇形例、分数入力を検証します。`npm run build`で公開用ファイルを生成します。OSの動きを減らす設定はCSS装飾に適用され、自動再生はユーザーが開始・停止できます。
