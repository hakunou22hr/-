# ネイピア数eの誕生 — 90秒制作版

React / TypeScript / Three.js / React Three Fiber / KaTeXによる、90秒の3D映像と探究教材。`material.json` を既存の教材一覧が自動検出するため、他の教材・一覧・ナビゲーションのソースは変更しません。

**原作 `Decoding_e.pdf` はこの制作環境に提供されていません。8ページとの原作照合は未完了です。** 原作準拠を確定する前の制作版として扱ってください。

## 使用方法

リポジトリのルートで `npm ci`、`npm run dev`。`/materials/birth-of-e/` を開きます。通常は解答非表示の探究モードで開始します。底a、接点x、増分h、分割nを変更し、仮説と測定結果を記録できます。記録と振り返りはこの端末のlocalStorageに保存し、JSONに書き出せます。保存先に個人情報は入力しないでください。

「考察を終えて解答を公開する」で微分公式・解説と映像が利用できます。「教師モード」では解説を展開して投影できます。これは端末上の表示切替であり、教員認証ではありません。動画は解答を含むため、探究を先に行う授業では上映を後にしてください。

2D/3D切替、回転・ズーム・移動、図形と数式の選択、文字拡大に対応。WebGL非対応時は2Dの収束図・数値表で実験を続行できます。

## 90秒の構成（2700フレーム）

|時刻|内容|
|---|---|
|0–18秒|年利100%の仮想複利モデル・都市模型|
|18–36秒|hの正負両側から0へ、未定義点と極限の区別|
|36–48秒|対数と指数の逆関数・同じ平面内のグラフ|
|48–64秒|割線から接線へ、底を変える実験|
|64–76秒|極限の定義、黄金色の立体e、近似値|
|76–90秒|自然対数の微分、動く接点と傾き|

台本と時刻は `src/model.ts` の `cues`。動画とWebは同じ `movieParameters`、`logA`、`secant`、`derivative`、`limitExperiment`、同じ `Scene` を使います。Webの自動映像は同じ収録音声の再生時刻を基準に同期します。MP4は独立したファイルで、通常のHTML videoで再生します。

数値計算は `Math.log1p` を用い、h=0を直接代入しません。割線と接線は別の計算です。h→0の数値観察は証明と区別します。3Dの奥行きは比較と視点のためで、通常の関数曲線はz=0にあります。収束シーンの座標変換は横軸−log₁₀|h|−1、縦軸10(f(h)−2.5)、奥行きは正負の比較です。2Dの収束図には実際の値を表示します。

## 検証

```
npx tsc -p materials/birth-of-e/tsconfig.json
npx vitest run materials/birth-of-e/src/model.test.ts
npm run build
```

既存rootのtsconfigはsrcのみを対象とするため、この教材の型チェックは別に実行します。

## 動画出力（Webの配信と別工程）

`render/README.md` を参照。フルHD 1920×1080、30fps、H.264/yuv420p + AAC、90秒。ブラウザの自動映像を1/30秒ごとの決定した時刻で描画し、FFmpegでMP4にします。無料のOpen JTalk音声とFFmpegで、有料APIは不要です。Remotionを必須にせず、同じモデル・Sceneを直接出力します。

`public/media/birth-of-e-90s.mp4` が動画、`public/media/birth-of-e-narration.m4a` がWebで共有するナレーション。原稿、収録時刻、素材のクレジットは本フォルダに保持します。

## 公開

既存のGitHub Pages workflowで `npm run build` のdistを配信します。PRをmainへマージすると公開されます。動画のレンダリングは配信workflowに含めず、完成MP4を事前に生成・登録します。main・既存の公開サイトを直接更新する操作はこの制作に含めていません。

## 検証の範囲

Chromiumで画面操作と390px幅を確認。実機のWindows 11、iPhone Safariは未確認です。Safariではインライン再生、ユーザー操作による音声開始、WebGL失敗時の2D代替を備えていますが、実機による性能・音声・ジェスチャー確認は公開前に必要です。
