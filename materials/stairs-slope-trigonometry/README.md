# 階段とスロープの三角比

React Three Fiber / Three.js / KaTeXによる数学Ⅰ「図形と計量」の探究教材。教材ポータルの数学Ⅰ・三角比カテゴリに自動登録されます。

## 利用

ルートで `npm ci`、`npm run dev`。`/materials/stairs-slope-trigonometry/` を開きます。`npm run build` は既存教材を含むPages用静的ファイルを生成します。有料API・外部CDN・アカウント不要。

観察→分解→予想→計算→検証。生徒は段を選び、三角形を取り出し、比を選択し、分母と丸めた数値を入力します。教師モードは全STEP、解説と正解、発光、投影文字、状態リセットを使用できます。考察はlocalStorageに保存します（リセットで消去しません）。光の演出は停止でき、端末の動きを減らす設定を初期値に反映します。

## 幾何

cmをそのまま3Dの単位とし、xを水平、yを鉛直、zを幅方向とします。d、θ、nに対しh=d tanθ、総水平長nd、総高さnh。i段目の踏面はy=(i+1)h、x∈[id,(i+1)d]。その後端((i+1)d,(i+1)h)は隣接スロープy=x tanθに接します。選択段の手前に、踏面と同じ長さの青い水平補助辺、金の鉛直辺、赤のスロープに平行な斜辺を同一平面で表示します。赤い斜辺はコンクリートに隠れない補助線として描画します。抽出時はこの三角形を形を保って浮かび上がらせます。角度は青い水平辺と赤い斜辺の間の円弧で表示します。1段の三角形は(id,ih)、((i+1)d,ih)、((i+1)d,(i+1)h)。50cmは水平辺、13°はその水平辺との角です。幅・段数は視覚化の設定で問題の既知寸法には使いません。

透過は材質の透明度、断面は幅方向に半分を切り出してスロープを非表示にします。2D断面もh/d=tanθで描画し、グラフはθを横軸、cmを縦軸に取ります。現時点では添付原図を取得できておらず、文面にある条件のみを使用しています。

## 検証

`npm test`：元条件の丸め、角度・奥行きの単調性、スライダー範囲端と全段数の接触点、水平基準、視点座標。`npm run build`：TypeScriptと全教材の静的ビルド。

Windows/iPhoneはWebGL対応ブラウザを想定。実機で回転・ピンチ・入力・保存を確認してください。3Dエラー時には2D図と入力を継続利用できます。
