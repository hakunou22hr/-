# 90°の向こうへ ― なぜ単位円を使うの？

90秒の数学映画と直接操作教材。既存の「触れる、単位円。」180秒版と「三角方程式（cosθ）③」は変更せず、別教材として追加します。

閲覧：https://hakunou22hr.github.io/-/materials/beyond-90-unit-circle/

MP4：https://hakunou22hr.github.io/-/media/beyond-90-unit-circle-90s.mp4

ライブラリの「数学Ⅰ」で「90°の向こうへ」「単位円」「三角比」で検索できます。

## 90秒の物語

0–12秒：斜辺2・高さ1・底辺√3の30°三角形。相似で比が不変。
12–27秒：斜辺を1にし、高さ1/2・底辺√3/2へ。
27–34秒：cosθ=x/1=x、sinθ=y/1=y、P=(cosθ,sinθ)。
34–42秒：点Pの軌跡が単位円を作り、横・縦のメーターが追従。
42–54秒：90°から120°へ。補助直角三角形は作れるが、120°自体は直角三角形の内角にできない。負なのは座標であり辺の長さではない。
54–72秒：sinθ=−1/2 は横線y=−1/2。全周で210°・330°。
72–82秒：cosθ=−1 は縦線x=−1。180°の1接点と三角形の退化。
82–90秒：数学Ⅰと全周を比較。210°=7π/6、330°=11π/6、180°=π。

数学Ⅰは0°≤θ≤180°、発展は0°≤θ<360°（0≤θ<2π）。360°を解として重複しません。

## 操作

三角形の大きさ、斜辺1への正規化、点Pと直線のドラッグ、交点のタップ、角度とkのスライダー、sin/cos、範囲、度/弧度、2D/立体背景、背景選択、動きを抑える設定、段階解答、リセット。

上部の実MP4と下部の自動解説は同じ数学モデル・描画関数で制作。「この時刻で止めて操作する」はMP4を停止し、その時刻の図形へ移行します。自動解説も一時停止・操作・同時刻からの再開が可能。MP4終了後は同じ操作canvasで探究できます。解答は初期非表示です。

背景はCanvasで計算した透視投影格子、立体リング、粒子、交点の光柱と床面の波紋です。背景に静止画は使いません。数学図は読みやすい正面表示を維持し、2D切替で立体背景を外します。自由な視点回転機能はありません。音声・BGMはありません。

## 検証・再生成

`node materials/beyond-90-unit-circle/tests/math.mjs`

`npm run build`

Chromium、Playwright、FFmpeg、日本語フォントを用意して、`PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node materials/beyond-90-unit-circle/render/movie.mjs`。既定はpublic/media/beyond-90-unit-circle-90s.mp4へ1920×1080・24fpsで出力。`CHECK_ONLY=1 OUTPUT=/tmp/check` は16時刻の実フレームと状態を出力します。

`.github/workflows/beyond-90-check.yml` は当該コミットのPages公開を待ち、実URLで操作・MP4再生・4画面サイズ・ライブラリ登録・既存教材保持を検証します。iPhone/iPadの物理端末・Safari検証とは区別します。
