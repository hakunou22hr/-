数式の道筋と、グラフの約束

F(x) = ∫₀ˣ (x − t) cos t dt = x I(x) − J(x)

I(x) = ∫₀ˣ cos t dt、J(x) = ∫₀ˣ t cos t dt。

積の微分と微積分学の基本定理より、F′(x) = I(x) + x cos x − x cos x = sin x。

映像のグラフ実演は x ≥ 0。金は正、青は負の符号付き面積。結論はすべての実数 x で成立します。
