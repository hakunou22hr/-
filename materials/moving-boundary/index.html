計算の道筋

F(x) = ∫₀ˣ (x − t) cos t dt

x は積分変数 t に対して定数。まず２つの積分に分解してから、積の微分法と微積分学の基本定理を使います。

F′(x) = ∫₀ˣ cos t dt + x cos x − x cos x = sin x

金の領域は正、青の領域は負の符号付き面積。映像のグラフ実演では x ≥ 0 を扱います。結果の式はすべての実数 x で成立します。
