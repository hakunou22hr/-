# 不定積分と原始関数 2D・3D探究

数学Ⅲ／積分法・不定積分。教科書136ページの例題1の2問、練習2の3問に対応する、原始関数と導関数の関係を発見する教材。

## 起動・公開

教材ライブラリの「数学Ⅲ」または「不定積分」で検索し、教材カードから起動する。

公開予定パス：`https://hakunou22hr.github.io/-/materials/antiderivative-explorer/`

既存のPagesワークフローはmainへのpush時に全教材をビルドする。この変更をmainにマージ後、そのワークフローの成功で公開される。PRブランチは自動公開されない。Pagesはリポジトリで有効。公開URLは標準のリポジトリPagesパスで、ローカルでも `/-/` 配下で起動を検証した。

`material.json`が教材一覧の登録情報。Viteの既存自動検出で新しいHTMLエントリーをビルドする。サムネイルはSVGをVite経由でバンドルし、Pagesで404にならないURLを教材一覧に渡す。既存教材・公開ワークフロー・依存パッケージは変更しない。

## 操作

1. 5問から選び、「問題理解→式変形→グラフ探究→積分計算→微分による検証」を進める。
2. xスライダーで2D上の点、接線、3D上の点を一緒に動かす。再生、スロー、停止、±0.05のコマ送りを使える。
3. Cスライダーで高さだけを変え、傾きの数値が同じままであることを確認する。正負の区間を切り替えてC₊／C₋を別々に設定できる。
4. 3Dはマウス／指1本で回転、ホイール／指2本で拡大・移動。金色の曲線が選択中のC。3Dのスライダーも2Dと同期する。
5. 対数モードは基本関数1/xに切り替わる。区間とlog x／log(-x)／log|x|を切り替え、実数としての定義域を比べる。
6. 面積モードは同一区間内のaとxで操作する。x<aでは積分の向きが反転する。Cを変えても面積の値は変わらない。
7. 探究は予想を入力してから実験・解説・振り返りへ進む。入力はページを開いている間だけ保持する。
8. 教師用解説、段階的ヒント、公式一覧、確認問題も利用できる。「初期画面」で操作状態を戻す（探究の記述は保持）。

モバイルにはグラフ近くにもx／Cと再生・コマ送りの操作を配置。発光・軌跡を止めたり、低負荷モードに切り替えられる。OSの「視差効果を減らす」設定がある場合、発光演出は初期状態で停止。3DのWebGL起動に失敗した場合は説明を表示し、2D探究を使える。

## 数学と表示の約束

- すべて自然対数。5問の原始関数は依頼の答えと一致する。
- 練習2 (3)はx>0。他の問題はx≠0で、正負を別々の連結区間として扱う。
- x=0をサンプル・点・接線・面積・3D曲面が跨ぐことはない。再生は区間端で停止する。
- 通常は0.15≤|x|≤6、「0にさらに近づく」では0.015≤|x|≤6。0まで到達する操作は用意しない。
- 面積A(x)はF(x)−F(a)から計算する。色つき領域は各零点で分割し、軸より上を緑、下を赤で表示する。x<aの向きの反転は数値と説明で明示する。
- F+Cのx方向微分はf。3Dではx軸がx、y軸がC、z軸がF(x)+Cで、接線方向は(1,0,f(x))。
- 3Dは−4≤C≤4、|z|≤10の範囲を表示。描画範囲を超えた部分は切り落とし、境界を跨いで接続しない。2Dも表示範囲外の点を明示する。発散を有限値で置き換えて解釈しない。
- 式変形では各項の関数、積分計算では各項の原始関数を点線で重ねる。和の実線は同値な式の間で変えない。検証段階は数値微分の接線と解析的接線を重ねる。
- グラフはサンプリングによる描画近似。面積の数値は原始関数による評価で、数値微分は独立な近似検算。証明は表示した解析的微分式による。
