# 定積分と微分

数学Ⅲ。F(x) = ∫₀ˣ (x−t) cos t dt を、分解・部分積分・ライプニッツの公式の3つの道で微分する90秒映画。作品タイトルは動画に挿入せず、ページと教材一覧で表示します。

- `../../public/media/teisekibun-to-bibun/teisekibun_to_bibun_90s.mp4`：同じ90秒の1280×720配信用版。Pagesの容量に収めるため、原版の保存と配信を分けています。

## オリジナルの動的背景

背景は静止画像ではなく、Canvasへ透視投影する3D座標、カメラの旋回・前進、青紫の90本の光フィラメント・黄金の42層の渦、密度のある流れる粒子、数式、動くノイズ雲、渦、ガラスの立体格子と交差する波面から毎フレーム生成します。`model.js` の単一時間から、数式の位相・項の移動・衝突・波紋・パラメータ依存グラフ・背景を決定。シーク履歴に依存しません。参考画像は素材として複製していません。

KaTeXで生成した透過PNGを最終解像度で合成。分数・添字・上付き・積分範囲をラスタライズ後も保持します。ページの解説も同梱KaTeXで組版します。

## 数学

1. F = x∫cos t dt − ∫t cos t dt。積の微分で生じる +x cos x と −x cos x を相殺。
2. tで部分積分。原始関数 (x−t) sin t − cos t を0とxで評価し、F = 1−cos x。その後xで微分。
3. 上端の寄与 f(x,x) は0。∂f/∂x = cos t を既存区間にわたって積分する寄与が残る。

いずれも F′ = sin x。第3幕の図は正のxでの例です。一般の実数xでも向き付き積分により同じ等式が成立します。青は既存区間での関数の変化、金は新しい小区間。後者の面積は O(Δx²) で、微分の極限では0となります。表示用の小区間幅は Δx = 0.12。

## 制作・検証

- `math-source.js` → `render/generate-math.mjs`：36点の数式素材。
- `film.js`：ブラウザとNodeに共通の決定的描画。

依存関係は既存リポジトリのKaTeX、`render/package.json`のPlaywrightと@napi-rs/canvas。Noto Sans CJK JPを使用。既存の参考教材は `../trig-integral-cinema/`。既存教材は変更・置換しません。

## 映像の改訂 v2

参考画像の3つの世界に合わせ、暗く細い背景を廃止し、青紫の奔流・黄金の渦・俯瞰するガラス格子を`stage.js`で新規描画。全画面を暗くする処理を除き、数式部分だけに局所的な暗い下地を置いています。12秒の背景モーションは`review/background-motion-study-12s.mp4`、3場面の見本は`review/stages-v2.jpg`。`render/stage.check.mjs`は発光領域、彩度のある領域、時間差の動き、俯瞰カメラを検査します。

## 黄金の渦の粒子強化 v2.1

第2幕に1440個の渦粒子と160個の流入粒子を配置。大小の粒子、湾曲する光跡、前後に分かれる深度、明滅する粒子核を追加。外周から中心への流れと渦の回転を強めています。他の2つの背景と、数式のタイミングは維持。`render/motion-study.mjs --golden`で8秒の黄金渦見本を生成できます。


### v2.2 空間演出
「積分の中に眠る円」の奥行きのある画面構成を参照し、閉じた数式回廊とは異なる開放型の干渉計空間を制作。ねじれた菱形フレームが奥から手前へ移動し、左右の光の帆に視差が生じます。黄金の渦は３本の傾いた軌道と双方向のらせんジェットを追加し、吸い込む粒子と噴き出す粒子を同時に可視化。立体格子には伝播する光の波紋と上昇する粒子を追加。数式・字幕は独立した前景レイヤーに保ちます。参考教材自体のファイルは変更していません。
