# 三角方程式と単位円

数学Ⅰ・三角比の発展教材。入口は `index.html`。90秒の映画、同じ単位円を使う2D/3D探究、縦型30秒版を1ページに配置する。既存の `trig-equations-circle` 等の教材は変更しない。

## 数学

2 sin²θ + sinθ − 1 = 0 に t = sinθ、−1≦t≦1 を代入。2t²+t−1 = 2t²+2t−t−1 = 2t(t+1)−(t+1) = (2t−1)(t+1) より t=1/2,−1。

単位円と y=k の交点は (±√(1−k²), k)。k=±1 は重複を除き1点。高さ1/2は30°と150°、高さ−1は270°。0≦θ<2π の解は π/6, 5π/6, 3π/2。数学Ⅰの0°≦θ≦180°では30°、150°のみ。360°のスライダー端点は0°と同じ点で、発展の解の範囲には含めない。

描画座標の倍率Rは画面上の大きさだけを決める。計算は半径1の座標で行い、透視投影によって値を変えない。三角形の底辺の長さは |cosθ|、高さの長さは |sinθ|。符号付きの座標・sin値と区別する。xまたはyが0では三角形を非表示にして退化を説明する。

## 映画と実際の3D

- 0–12秒：sinθの文字が回転・縮小・移動しtになる。単位円と−1〜1の光の帯で範囲を示す。
- 12–25秒：因数分解の等式を正確に展開。因数・光・奥行きのある光跡が金と赤に分裂。tからsinθへ戻し、カメラが光の流れに沿って加速する。
- 25–48秒：粒子が単位円へ収束。水平線が伸び、実際に円と出会う時刻から衝撃波と粒子が放射。半径と直角三角形が30°から150°へ連動する。
- 48–65秒：水平線が下降し、交点2点が1点へ合流。270°の半径は下向きになり、三角形は退化する。
- 65–90秒：3点の半径と円弧が光り、円弧の成長と同期して度数法から弧度法の分数へ連続移動する。最後に3解を表示してカメラを引く。

光跡、格子、金色の軌道、床、交点、光源、星、衝撃波、放射粒子は実際の3Dオブジェクト。静止した背景画像は使わない。光の小さなビルボードはコードで生成した放射グラデーションで、背景の代用ではない。角度・因数分解・交点イベントから色、光跡の位置・回転・発光が変わる。

## 操作

映画終了後に探究へ切り替わる。最初の解答は非表示。角度を1°刻み、高さを0.01刻みで操作し、交点を探す。「因数分解→座標→角度」の3段階で解答を確認する。30°/150°/270°の移動ボタンは角度の解答を開いた後に表示する。

2Dは正面の平行投影、3DはOrbitControlsで回転・拡大縮小。数学Ⅰと発展で解の個数を比較する。「円全体の交点数」と「選択した角度範囲での個数」は別に表示する。リセットは角度・高さ・表示・解答を初期化する。

低性能・小画面では粒子を減らしBloomを省略し、描画時間が長い場合も解像度と発光を調整する。WebGLが使えなくても同じ計算結果をSVGの2D代替表示と本文で確認できる。MP4はWebGLに依存しない。

## 検証・再現

Viteを5173番で起動して以下を実行する。FFmpeg、Chromium、Playwrightが必要。`PLAYWRIGHT_MODULE` / `CHROMIUM_PATH` は書き出しで上書き可能。

```sh
node materials/trig-equation-unit-circle/render/preview.cjs
node materials/trig-equation-unit-circle/render/check.cjs
node materials/trig-equation-unit-circle/render/export.cjs 30
node materials/trig-equation-unit-circle/render/export.cjs 90
npm run build
```

`?render` はリアルタイム90秒。`?render&export` は決定的なフレーム取得、`&portrait` は30秒の再編集。`window.seekFilm(t)` で任意時刻を描く。書き出し成功と長さ・解像度・フレーム数の確認後にだけ公開パスへMP4を移す。

検査は201種類の高さ、因数分解、3解、角度範囲、描画された座標と数値の一致、退化、動く背景とカメラ、段階的解答・リセット、3Dドラッグ、タッチのスライダー、390/844/1024pxの画面を含む。実機iPhone・iPad・電子黒板での検査は未実施。ブラウザのモバイル・タッチ模擬による検証と区別する。リアルタイム描画のfpsは端末による。書き出しは24fps。

90秒MP4は `trig-equation-render.yml` で同じタイムラインを0–30、30–60、60–90秒に分けて並列生成することもできる。各720フレームを結合し、2160フレーム・90秒を検証して専用ブランチに保存する。最終色調整は `color-patch.cjs` でScene 4の冒頭だけを再描画する。下降する水平線と交点は、初めから赤に統一する。

ライブ再生は実経過時間で進める。処理落ちでフレームが少なくなっても90秒のタイムライン自体は引き延ばさない。

下降する線が上半分にある間は交点が左右に広がり、その後に合流する。字幕は最下点を調べる表現とし、一様に近づくとは説明しない。

動的な小数の読み取り値は表示桁で丸めた参考値。解の角度と座標は正確な分数・根号で示す。

冒頭改訂v3：0〜11秒の奥の星空・光跡・カメラの前後移動を停止。赤・青・金の枝分かれした3D稲妻、減衰する余光、連動する照明に置き換え。11〜12秒でカメラを次の場面へ接続。90秒版の冒頭12秒と縦版の冒頭3秒を再生成。音声はありません。
