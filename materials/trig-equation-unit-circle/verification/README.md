# 完成動画と動作確認

- 30秒：1080×1920、24/1 fps、720フレーム、H.264。全体デコード成功。
- 90秒：1920×1080、24/1 fps、2160フレーム、H.264。全体デコード成功。

`check.json` は201種類の高さと境界近傍、因数分解、解、描画座標、場面進行、PC操作、段階的解答、範囲切替を検証。`touch-fallback.json` はタッチ回転・ピンチ・WebGLなしのSVG代替を検証。390px縦、844px横、1024pxの画面を確認。

`media.json` は完成ファイルのSHA-256。公開後も同じファイルであることと、動画終了から探究への切り替えをGitHub Actionsで検査する。背景改訂v2では両動画を全フレーム再生成。`check.json` で背景の光跡のスケールが常に1であることと「≦」の表示も検証。
