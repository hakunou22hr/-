# 三角方程式（cosθ）― 単位円への旅

映画90秒、縦型Instagram動画30秒、操作できる単位円を持つ新規教材です。既存教材は保持し、ライブラリに「三角方程式（cosθ）」フィルタータブを追加しています。

## 数学と範囲

2cos²θ−5cosθ+2=0を、t=cosθと値域−1≦t≦1の確認、二次式、因数分解、cosθへの戻し、範囲外の候補2の排除、単位円の交点の順に説明します。

単位円とx=kの交点は、|k|<1なら(k,±√(1−k²))、|k|=1なら(k,0)、|k|>1なら無し。k=1/2では(1/2,±√3/2)。全周0≦θ≦2πではπ/3と5π/3、通常範囲0°≦θ≦180°では60°だけです。スライダーは0°〜360°まで動かせますが、全周の360°も範囲に含めます。x=1のときは交点は1つですが、角度は0°と360°の2つです。

回転中の半径の先端のx座標は変わります。二つの解の位置でのみx=1/2へ戻ります。高さは辺の長さとして|sinθ|を表示し、座標のsinθの符号とは区別します。

## 実装

- src/model.ts：映画・操作教材共通の数学、角度、交点、範囲、字幕、時計。角度0.1°刻みの弧度法はπの既約分数で表示。
- src/World.ts：同一のThree.jsモデルと描画。数学の半径1を一様に2.2倍して表示。48個の多層リング、4,200個の粒子、座標格子、赤い直線と崩壊粒子、正しい交点の2つの衝撃波、変形する直角三角形、反時計回りの円弧、カメラを同じ時刻で制御します。
- src/main.tsx：正確なKaTeX数式・字幕・3D表示と、スライダー、2D／3D、度数法／弧度法、通常／全周範囲、段階的解答、リセット。
- 2Dは正投影。3DはOrbitControlsで回転・ホイール／ピンチズーム。幾何学位置は共通です。
- 映画終了時に探索画面へ移動し、同じモデルをk=1/2、θ=360°で引き継ぎます。初回の探究画面はk=1/2、θ=0°で解答非表示。解答は元の方程式のものと明記し、任意kの操作結果と区別します。

背景は静止画像ではありません。リングは実際の3Dトーラスで、移動・回転・縮小・二分を行います。巨大／無限空間は有限モデルを奥へ続ける表現です。数式は別のKaTeXレイヤーで、中央の数式には時計同期のCSS透視変形・発光・置き換えを使います。数学の曲線を生成画像へ描かせていません。

## 再編集・描画

ルートでnpm ci。npm run devでライブラリを起動。単体の固定ビルドは以下。

```
npx vite build --config materials/trig-equation-cinema/vite.config.ts
npx vite preview --config materials/trig-equation-cinema/vite.config.ts --host 127.0.0.1 --port 8810
APP_URL=http://127.0.0.1:8810/ PLAYWRIGHT_MODULE=/absolute/playwright/index.mjs OUTPUT=/absolute/output/trig-equation-90s.mp4 node --experimental-strip-types materials/trig-equation-cinema/render/render.mjs
```

EDITION=shortで縦版を描画します。CSS座標1280×720／720×1280をDPR1.5で描画し、3Dと文字をネイティブ1080pで書き出します。単なる完成画像の拡大ではありません。DURATIONとSTARTで部分再描画もできます。captions.mjsが字幕と台本を生成します。assemble-review.mjsは、説明順序を調整した冒頭部分の差し替えや、短版の4要点字幕の焼き込みに使う任意の補助スクリプトです。

## 1.1.0：授業導入・分数・度数法

最初の6秒に、生徒のいる生成教室画像を奥行きメッシュへ配置した導入を追加。カメラが黒板の方程式へ前進し、光の回廊へ入ります。生徒自身の動作を生成した実写動画ではありません。縦版では教室全体を収めてから進入します。

t=1/2の候補ラベルはKaTeXの上下分数へ統一。本編の範囲・解・交点ラベルを0°≦θ≦360°、θ=60°・300°に統一しました。弧度法と通常範囲の比較は、操作教材の選択肢として残しています。

数学モデルの閉区間化に合わせ、k=1では1交点に0°と360°が対応することを反映しました。本編0〜12秒・64〜90秒、短版0〜5秒・23〜30秒を再描画し、既存の正確な3D区間とフレーム単位で接続します。分数ラベルと縦版の数式パネル・字幕は、同じ時計のKaTeXレイヤーから再描画します。

## 弧度法のまとめ（v3）

本編84〜90秒で60°＝π/3、300°＝5π/3を対応させ、0≦θ≦2πの解を分数で表示。縦版の終盤にも同じ対応を表示します。
