# 半円を「3本＋短い不足分」で説明する改訂

90秒版の説明の順序：

1. 31–34秒：半径1本を青い円弧へ巻く。
2. 35.2–38.2秒：2本目を緑で足す。
3. 39.4–42.4秒：3本目を黄金色で足す。
4. 42.4–47秒：3本分で止め、半円の残りを赤い点線で示す。
5. 47–50.2秒：不足する正確なπ−3本分を赤い帯で巻く。表示は「約0.14本分」。
6. 50.2–54秒：「3＋0.14159…＝3.14159…」。半円が完成。
7. 54–56秒：この本数をπと呼ぶ。その後で L＝πr に進む。

ものさしの3つの区画はそれぞれ半径1本分、赤い区画はその約14％。巻いた弧長・数値・ものさしは `half-lesson.js` の同じ値から計算する。30秒版も同じ数学タイムラインを利用。

`states.json` は3本で止まること、赤い部分の中間、正確なπでの完成、両画角の数式エラーとレイアウトを検証。`patch-30.json` と `patch-90.json` は書き出したフレーム範囲、完成フレーム数、範囲外の画面が元の映像と対応することを検証する。

背景・光源・粒子・カメラの制御は変更しない。90秒版の30–58秒、30秒版の11–21.5秒だけを再描画し、前後には元の映画を使用する。再圧縮に伴う軽微な画素差は、範囲外の複数時刻を比較して検査。

`wide-*.jpg` と `portrait-*.jpg` は修正済みMP4から取り出した確認画像。画像一覧は `../cinema/index.html`。
