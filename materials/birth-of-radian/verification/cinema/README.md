# 映画版の検証

- `media.json`：完成した90秒・30秒MP4の解像度、秒数、24fpsの全フレーム数、SHA-256。両動画をFFmpegで最後までデコードして確認。
- `6.jpg`、`20.jpg`、`42.jpg`、`62.jpg`、`82.jpg`：完成した90秒MP4から直接取得。`index.html` で一覧表示。
- `timeline.json`：90秒版と30秒版の計122時刻を3D描画。5場面、中心角と接触弧長、カメラ位置、背景の時間変化、WebGLエラーを検査。16ケースの帯の長さの数値積分誤差は最大約8.7×10⁻¹⁰。
- `library.json`：90秒版を初期表示。30秒版への切り替え、再生、一時停止、最初から再生、チャプター移動、保存したMP4のハッシュ、390px幅、一覧カードの新版リンクを検査。

`npm run build` と `npm run test:trig-cinema` が成功。公開後はGitHub Actionsの `verify-radian-cinema-playback` が公開URLで動画のメタデータ・指定時刻・再生終了・30秒ダウンロードのハッシュを検査し、画面と結果をアーティファクトへ保存する。実機iPhoneでの確認は行っていない。
