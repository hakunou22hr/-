# 数学Ⅲの系譜 ― 極限・微分・積分へつながる数学

高校数学Ⅰ・A・Ⅱ・B・Cの知識が極限・微分・積分へ集まり、物理へ広がる様子を、ひとつの映像ステージで体験する教材です。小さなグラフを並べるダッシュボードではなく、主役の図を大きく描き、30Sceneを連続再生します。

## 操作

- **全編再生／一時停止**：1回の再生操作で最後まで進みます。標準速度で各Sceneは21秒、全編は10分30秒です。再生終了後に再生を押すと最初へ戻ります。
- **前・次・最初から**：前後のSceneへ移動します。前後の移動は停止状態で確認できます。
- **再生位置**：下部の細いスライダーで全編を往復できます。
- **速度**：0.5、0.75、1、1.25、1.5、2倍。
- **30 Scene**：Scene一覧を開いて選ぶと、そのSceneから連続再生します。下部の章ボタン、系譜の項目も同様です。
- **探究モード**：再生が停止し、Scene固有のスライダーや図のドラッグで操作できます。「動画へ戻る」で映画の再生位置へ戻り、全編再生で再開します。
- **キーボード**：入力要素にフォーカスがないとき、Spaceで再生／停止、左右キーで前後Scene。
- **全画面**：ブラウザーが対応している場合に利用できます。横画面を推奨します。

### 探究できること

単位円の点をドラッグするとsin/cos波と同期します。極限点の接近、割線と接線の差h、nの変化、振幅A・角周波数ω・位相φ、長方形数4〜128、積分の右端、位置・速度・加速度の時刻を操作できます。

ばねの単振動と最後の数学ネットワークはCanvasによる疑似3Dです。マウス／1本指で回転、ホイール／2本指のピンチで拡大縮小します。最後のネットワークでは点をタップすると、その概念の関係・数式を読み取れます。複素数、ベクトル、媒介変数、2次曲線、無限級数、回転体、曲線長、合成関数、高次導関数、ユークリッドの互除法、方べき、正規分布も紹介します。これらは追加の解説であり、独立したアニメーションSceneではありません。

## 数学上の約束

- 三角関数はラジアンです。周期は2π/ω。単位円の角度と波の横軸を同じ値で同期します。
- 数列は離散点で描き、線を関数のグラフとして扱いません。
- Scene 13のeは1、2、5、10、100、1000のnで比較します。n=∞の代入はしません。
- 割線の例はf(x)=x²、a=0.5。平均変化率は2a+h、接線の傾きは2a=1です。hは1から0.001まで操作できます。
- 極値の例はf(x)=x³/3−x。極大はx=−1、極小はx=1。f′=0だけでは極値を保証しないことを明記します。
- logの曖昧さを避け、自然対数は**ln x**と表記し、底e・定義域x>0を明記します。
- 区分求積は[0,1]でx²の**右端和**。上から正確な積分1/3へ近づきます。有限の近似を正確な面積とは表示しません。
- 位置・速度・加速度はm、sを用いたモデルx=t²/2、v=t、a=1。単振動はx=A sin(ωt+φ)、v=Aω cos(ωt+φ)、a=−ω²xです。
- 速度の積分は**変位**です。移動距離との混同を避け、一般には符号付き面積であることを説明します。
- 数学Aの整数・相似はそれぞれ互除法・方べきへの関係として扱い、微積分への直接の前提とはしません。
- シーン間の輪郭補間、カメラの移動、光の接続は理解を助ける演出です。補間途中の図を新しい数学的等式・定理とするものではありません。

## 技術・構成

HTML / CSS / JavaScriptのES module、Canvas 2D、KaTeXを使用します。KaTeXとフォントは既存Viteビルドに同梱され、実行時にCDNや有料APIを呼びません。認証も不要です。

| ファイル | 役割 |
|---|---|
| index.html | 単一ステージ、再生・探究操作 |
| style.css | 星空の暗い配色、レスポンシブ表示 |
| scenes.js | 30Sceneの字幕・数式・数学的関係 |
| math.js | 数学関数、再生クロック |
| render.js | 図・グラフ・輪郭補間・疑似3D |
| app.js | 操作、Scene同期、タッチ、描画管理 |
| material.json | ライブラリの教材登録 |
| math.test.js / render.test.js | 数学・再生・描画の検証 |

WebGL・Three.jsを使用しないため、WebGL初期化失敗やThree.jsロード失敗によるブラックアウトはありません。Canvasのコンテキストを利用できない場合や描画エラー時も、数式・字幕・Scene操作を維持して案内を表示します。

描画は有効なSceneだけ。再生中にrequestAnimationFrameを使い、停止・探究モードでは入力時だけ描画します。非表示タブでは描画を停止します。小さな画面では粒子数・発光量・描画頻度・devicePixelRatioを抑え、不要なWebGLリソースは生成しません。点の鼓動は再生中のみで、停止時は静止します。

## 開発・GitHub Pages

リポジトリのルートで既存の`npm install`、`npm run dev`を利用し、`/materials/math3-lineage/`を開きます。

```sh
npm run build
npx vitest run materials/math3-lineage/*.test.js src/materials.test.ts
```

既存の`src/materials.ts`が`material.json`を自動で読み込み、トップページの教材一覧と「数学Ⅲ」検索へ追加します。Viteも`materials/*/index.html`を自動でビルドします。トップページ・共通CSS・Pagesワークフローを変更する必要はありません。

mainへ反映すると、既存`.github/workflows/deploy.yml`が`dist/`をGitHub Pagesへ公開します。想定URLは **https://hakunou22hr.github.io/-/materials/math3-lineage/** です。カスタムドメインなどPages設定が変わっている場合はその公開ベースURLに合わせてください。
