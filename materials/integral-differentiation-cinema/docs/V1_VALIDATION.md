# 検証記録 — 定積分と微分法

制作日：2026-10-15（日本時間）。ソース初版：f253f817c55d39b327242678b9f043b13ca672f3。

- PC版：1920×1080、90.000秒、2700フレーム、30fps。
- Instagram版：1080×1920、30.000秒、900フレーム、30fps。
- H.264 High、yuv420p、AACステレオ48kHz、MP4 faststart。
- 全3600フレームで数式・字幕の画面内配置、グラフとの分離を検査。縦型重要領域は x6–82%、y14–75%。
- FFprobeで寸法・時間・fps・フレーム数・コーデックを検証し、FFmpegで両方のファイル全体をデコード。
- Chromiumで両方の再生・非ミュート音声デコード・シーク（26秒／82秒）・ダウンロード名を検証。幅390pxでページの横はみ出しなし。UI検証ではMP4をローカルRange対応サーバーで配信。
- 画像サンプルで公式、例題、打消し、結末を目視確認。
- 81点ずつの数値積分・数値微分により基本定理、sin、t exp(t)、F(x)=∫₀ˣ(x−t)cos(t)dt=1−cos(x)、F′(x)=sin(x)、相殺項を検証。
